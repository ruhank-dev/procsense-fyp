# MPFB patient provenance

Generated locally for ProcSense using MPFB 2.0.18 (official tag v2.0.18, source commit prefix d0a32e5) and Blender 4.5.14. Graphical assets come from the MakeHuman system asset pack and CC0 Faceunits 01 / Visemes 02 packs. Sources: https://static.makehumancommunity.org/about/license.html and https://static.makehumancommunity.org/assets/assetpacks.html. Core asset contributors include Data Collection AB, Joel Palmius and Jonas Hauquier; facial packs were contributed by Mika Suominen. The source software is GPL-3.0-or-later and remains in a locally ignored tool cache; generated graphical assets are CC0.

Build recipes, the visual preset and archive SHA-256 values are under unity/Tools/MPFB. Native source and export reports are under ignored build/mpfb/output. Unity import preserves GUIDs, remaps to URP Lit and caps textures at 2K with Android ASTC 6x6. The model has a valid Humanoid Avatar, 53 bones, 67 body facial/speech shapes and 41,796 triangles across eight skinned parts. Bed linen is separately authored by the Blender recipe. This is one provisional visual adult-male preset, not a demographic/clinical-sign binding.

The separate MPFBPatientReview scene preserves the committed PatientBay fallback. Both arms are posed via bones, and sensor sockets/wristband follow the arm/hand/finger hierarchy. Its Avatar remains available; the Animator is disabled to preserve this fixed review pose. Facial shapes are usable and tested, but automatic breathing, clinical expressions, voice/lip-sync and body physics are not implemented. Headset performance, comfort and clinical appearance acceptance remain pending.
