# Hospital surface sources

Imported 14 October 2026 for PatientBay, Corridor and OT presentation.

All six source JPG files are unmodified 1K maps from ambientCG, released under
[CC0 1.0](https://docs.ambientcg.com/license/). Raw redistribution in the project
is permitted. The archive copies remain in the ignored Temp/EnvironmentSources
directory and are not required by a player build.

| Source | Use | Physical texture repeat |
|---|---|---|
| [Wood050](https://ambientcg.com/view?id=Wood050) | Pale wood laminate lower wall panels | Artistic panel mapping |
| [WoodFloor040](https://ambientcg.com/view?id=WoodFloor040) | Bay and corridor wood-effect flooring | Approximately 1.9 m |
| [PaintedPlaster017](https://ambientcg.com/view?id=PaintedPlaster017) | Subtle painted-wall normal map | Artistic mapping |

Each asset includes Color and NormalGL maps. The plaster color map is retained as
source but the wall material uses a uniform warm paint color to avoid the scan's
hairline cracks. Materials use conservative smoothness and normal strengths.
Import settings: mipmaps, repeat, 1K maximum, 4x anisotropy; Android ASTC 6x6.

Ceiling, trim, OT floor, frosted window backing and curtain colors are authored
materials. The gathered curtain meshes, ceiling grids and light fixture meshes
are generated by Assets/Editor/Environment/HospitalFinishes.cs. Curtains are
static presentation meshes; there is no cloth simulation or transparent glass.

The Editor utility applies finishes once to existing saved shells and refuses
to overwrite an existing Hospital finishes root. It preserves equipment,
navigation, wall/floor colliders and asset GUIDs. Do not run the prototype scene
rebuild command: it would replace authored scene layouts.

Quest frame timing and headset visual acceptance have not been measured.
