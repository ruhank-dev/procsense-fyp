## DC-01

**Frame-time cost with the local model and the recogniser running beside the simulation**

Needs: The desktop with the VR scene (Editor play mode or a PC build) and Ollama running; a Quest linked to the PC if the scene is streamed

Prepared (already in the repository):

* `tools/ai/benchmark.py`
* `docs/research/model_benchmarks.md`

Procedure:

1. Start the VR scene with no model loaded; record 2 minutes of frame time (Unity Profiler or OVR Metrics: average and 99th percentile frame ms).
2. In a terminal run: ollama run qwen3.5:4b-q4_K_M "hello" so the 4B model is loaded, then repeat the 2-minute recording while `uv run --project tools tools/ai/benchmark.py b0 --model qwen3.5:4b-q4_K_M --runs 20` runs.
3. Repeat with the speech recogniser busy (the voice client sending a clip every 10 seconds).
4. Write the three pairs of frame-time numbers and the BT0 line of the benchmark in the result file.

**Pass rule:** Average frame time stays within the headset's refresh budget (13.9 ms at 72 Hz) in all three runs, and the 99th percentile does not exceed 1.5 times the budget. If it does not, write which run failed; the model then runs on the laptop (ADR-0010).
