# p1-ai-language-s21 — Direct controlled synthetic development set (500 items); the abandoned synthetic-data factory removed

Milestone: **M10 P1 platform — backend, AI, voice input**

## What
Owner decisions of 21 October 2026: human effort is reserved for the final Meta Quest test (the manual EX-01 workflow stays paused, tooling kept); a multi-model cloud synthetic-data factory was tried in three bounded free-plan pilots (2.75, 25.6 and 23.1 percent accepted) and **abandoned** as too costly in time and cloud usage; its code, tests, reports, artefacts and registrations were removed. The replacement is a **directly written, controlled synthetic development set of about 500 items** with no cloud call.

1. **Design** (`docs/research/direct_synthetic_dev_set_design.md`, approved): coverage matrix (150 credit-eligible ordinary, 45 performed-but-ineligible, 140 not performed, 55 genuine critical, 30 critical-topic without claiming completion, 50 no-act, 30 multi-intent; 174 credit-eligible and 326 no-credit; 91 safety-sensitive; 33 contrast sets of 198 items), style and persona plan (P5 and P7 and four topic groups reserved for the later held-out set), exclusions and open issues.
2. **Ground truth first**: every specification (objective, situation, actor and recipient, step and window, waiting question or read-back, contrast set and role, expected credit) is derived from the approved rules (`taxonomy.json`, `mapping.json`, rubric rules, ADR-0005/0022/0023) and frozen with a SHA-256 manifest before any sentence exists; sentences are written per specification id in a separate file with no label field; a sentence that does not fit its specification is discarded, never relabelled.
3. **Validation**: deterministic only (schema, specification hash, window and state validity, duplicates, historical leakage, diversity, form and modality cues, manifests), plus the author's own semantic review against the frozen specification. Generation and review are both AI-assisted (the same model) and are **not independent human validation**.
4. **Cleanup**: the factory modules, their 47 tests, the three pilot reports and sample pages, the pilot outputs and logs, the plans, the pipeline evidence and the DT items that existed only for it were removed; the useful findings were moved into DT-241 (taxonomy boundary ambiguities), DT-242 (speech-form semantics left open), DT-243 (delegated communication) and DT-244 (claims of earlier completion, a possible guard gap); the reusable leak and diversity helpers live in `tools/synth_dev/diversity.py`.

## Why
The semantic reader needs controlled, diverse development data whose labels come from the approved rules rather than from a model's reading of a sentence. The factory showed that a generate-and-judge pipeline spent more time and cloud usage than the data was worth, but its pilots exposed real ambiguities in the definitions, which are now tracked.

## How to implement
`tools/synth_dev/` (plan, validate, report; diversity helpers) and `tests/synthetic_dev_v1/` (frozen specifications, manifest, utterances, discard log, open issues, report). Development data: failures may be inspected and used to improve ProcSense; results on it are never reported as independent generalisation. A fresh held-out set is built later and frozen before scoring.

## Verification
`uv run --project tools tools/synth_dev/validate.py --check`; the full local CI.

## Files changed
`docs/research/direct_synthetic_dev_set_design.md`, `tools/synth_dev/`, `tests/synthetic_dev_v1/`, `docs/deferred-tasks.md` (DT-241 to DT-244), pause banners on the EX-01 manual documents, plans and registers.

## Status (21 October 2026)
Design approved; factory removed; the 500-item development set is generated and validated (see the report in `tests/synthetic_dev_v1/`). Nothing is scored; no guard, threshold, cue, engine, flag or frozen-set change.

## Dependencies
p1-ai-language-s20 (the layered evaluator, the freeze semantics), p1-ai-language-s19 (findings).

## Common issues
The same model writes and reviews, so blind spots are shared; reports say so. The no-credit majority (65 percent) flatters accuracy, so per-class and false-credit numbers must be shown.
