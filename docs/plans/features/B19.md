| Purpose | Diverse test sets. |
| Architecture and model or algorithm | Qwen3.5 9B paraphrase; label carried; 10 percent human audit. |
| Models | MC-01 |
| Data | — |
| Input schema | `ScriptedItem{text, label}` |
| Output schema | `Items[{text, label, source}] + data card` |
| Processing flow | paraphrase → dedupe → audit sample → card |
| Validation of outputs | Audit agreement at least 95 percent. |
| Errors | Timeout or server error: one retry, then hand-written sets; logged with prompt version and model digest. |

| Model unavailable | Feature switch reports off; hand-written sets. The session never waits on the model. |
| Invalid input | Inputs are schema-validated before the model is called; invalid input is a 4xx with field errors. |
