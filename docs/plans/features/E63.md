### E63.c1 — On-device ASR

| Field | Value |
|---|---|
| Kind | AI (pretrained) |
| Status | Implemented but incompletely tested |
| Purpose | Standalone. |
| Architecture and model or algorithm | Small Whisper-class model on device. |
| Models | MC-05 |
| Data | — |
| Input schema | `audio` |
| Output schema | `text` |
| Processing flow | transcribe on device |
| Validation of outputs | WER set. |
| Errors | Timeout or server error: one retry, then desktop ASR; logged with prompt version and model digest. |
| Hallucinations | Output must match a JSON schema whose enums are approved ids; the grounding validator rejects invented drugs, values, diagnoses, events and hidden facts. |
| Inconsistent results | Output is cross-checked against the structured case or facts it was given; any mismatch rejects it. |
| Model unavailable | Feature switch reports off; desktop ASR. The session never waits on the model. |
| Invalid input | Inputs are schema-validated before the model is called; invalid input is a 4xx with field errors. |
| Tests | WER; latency |
| Metrics | WER |
| Baseline comparison | Desktop ASR. |
| Acceptance | WER within 5 points of desktop. |
| GTX 1660 SUPER (desktop) | faster-whisper small.en or medium.en with int8 is expected to fit beside a 4B LLM on the desktop (upstream lists large-v2 int8 at about 2.9 GB); exact VRAM to be measured. |
| RTX 4050 Laptop | Possible, but competes with Unity rendering; prefer the desktop or CPU int8 small.en. |
| Memory | CPU fallback with small.en int8 on the Ryzen 5 2600 (6 cores) is expected to be near real time; to be measured. |
| Latency | Under 1.5 s from end of speech to text. |
| Deployment | Part of the inference service; push-to-talk audio streamed from Unity. |
| Tasks | p2-ai-extensions-s01 |
