## 1. Intended user experience

Each generated patient feels like a person: age, background, medicines, allergies, worries and way of speaking all fit the illness and each other.

## 2. What exists and what is missing

**Exists in the repository:**

- fixed patients in 53 case files
- authored distractor identities (DS-0012)
- fasting, allergy and medicine tables

**Missing:**

- profile generator
- persona wording
- consistency checks for generated profiles

**Deterministic foundation:** Constraint table for age, sex, pregnancy, allergy-medicine and comorbidity-medicine compatibility.

| Field | Value |
|---|---|
| Kind | AI (LLM) |
| Status | Implemented and tested |
| Purpose | Natural story and voice. |
| Architecture and model or algorithm | Qwen3.5 9B, schema with text fields and persona tag enums. |
| Models | MC-01 |
| Data | — |
| Input schema | `Profile + persona tags + allowed facts` |
| Output schema | `ProfileText{presenting_story, social_context, speech_style}` |
| Processing flow | prompt → schema check → grounding validator → store in package |
| Validation of outputs | Grounding validator (no fact absent from Profile). |
| Errors | Timeout or server error: one retry, then template story; logged with prompt version and model digest. |
| Hallucinations | Output must match a JSON schema whose enums are approved ids; the grounding validator rejects invented drugs, values, diagnoses, events and hidden facts. |
| Inconsistent results | Output is cross-checked against the structured case or facts it was given; any mismatch rejects it. |
| Model unavailable | Feature switch reports off; template story. The session never waits on the model. |
| Invalid input | Inputs are schema-validated before the model is called; invalid input is a 4xx with field errors. |
| Tests | grounding mutations; rater realism study |
| Metrics | realism rating; validator rejection rate |
| Baseline comparison | Template story. |
| Acceptance | Realism rating higher than template; zero ungrounded facts delivered. |
