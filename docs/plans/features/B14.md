## 1. Intended user experience

Results look like a real patient's: a septic patient's white count, CRP and lactate rise together; a repeat moves the right way; nothing is out of character for the illness.

## 3. The AI in this feature (seven questions)

| Question | Answer |
|---|---|
| 1. What is the AI supposed to do? | Learn joint distributions of linked results conditioned on condition and severity. |
| 2. Why is AI useful here? | Independent band draws break relationships (high WCC with normal CRP); a learned joint model keeps them. |
| 3. Which method for which part? | Statistical learning (Gaussian copula per condition; Bayesian network over discretised findings where data is thin) fitted offline; deterministic bounds. |
| 4. Deterministic parts still needed | Bands, plausibility, VR-CM. |
| 5a. AI already implemented | None. |
| 5b. AI missing | Learned joint models and their evaluation. |
| 6. What we must build | Fit copulas from MIMIC demo where n allows, expert-set structure from the KB otherwise; release as packs. |
| 7. How we prove it beats a simple baseline | Correlation error and VR-CM violation rate versus independent band sampling. |
