## 1. Intended user experience

Problems appear in the trainee's problem list only when they discover them by asking, examining or reading a result; free-text orders are understood.

## 2. What exists and what is missing

**Exists in the repository:**

- 156 discovery rules for 64 cases (DT-091), AI-reviewed, awaiting an independent clinician
- semantic interpreter of free-text orders: Gemma 4 31B Cloud reads the sentence in its scenario context and proposes one catalogue item, read back and released by the trainee's yes

**Missing:**

- independent clinician review of the discovery rules (docs/research/clinician_signoff.md)
- a human-authored evaluation set for the spoken-order reader (EX-18)

**Deterministic foundation:** Discovery rules.
