# Free 3D models — visual references only

> **Decision (07 October 2026):** every item is built with **our own Blender Python script**. These free models are **only for the team to look at** (style, proportions, detail ideas). None is imported into the project.

**Search date:** 07 October 2026. Every model below is **free to download** (searched with Sketchfab's `downloadable` filter; Poly Haven is entirely free).
They are references only — nothing here is imported.

**How it was found:** Sketchfab search API (109 queries) + Poly Haven catalogue. Name, author, triangle count and link come from
the API. The *Reviewed* table was also checked visually (thumbnail) by the developer — the recommendation reflects how clinically right it looks.

**Reference value key** (how useful it is to look at while scripting): **USE** = strong reference · **CONSIDER** = useful reference · **PARTIAL** = covers part of the item · **REFERENCE** = layout/style reference · **NO** = not useful.

**Can't be known without downloading:** whether doors/drawers/buttons are separate parts, texture quality, scale. Check when you open it.
