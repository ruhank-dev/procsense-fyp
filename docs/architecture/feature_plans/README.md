# Feature plans: where they are

The complete implementation plans of all 69 features are **not stored here**. The one canonical copy of each is `docs/plans/features/<ID>.md`, generated by `tools/plans/pipeline_docs.py` from [../procsense_full_pipeline.json](../procsense_full_pipeline.json). This folder is only an entry point so the plans are found from the architecture set; do not add plan files here.
