| Field | Value |
|---|---|
| Kind | AI (pretrained, infrastructure) |
| Status | Blocked |
| Purpose | Serve. |
| Architecture and model or algorithm | Ollama with Qwen3 tags; benchmark both GPUs. |
| Models | MC-01; MC-02; MC-04 |
| Data | — |
| Input schema | `benchmark prompts` |
| Output schema | `BenchmarkReport{model, gpu, vram, tok_s, ttft, schema_valid, unity_coexistence}` |
| Processing flow | install → pull → run protocol on GTX 1660 SUPER → run on RTX 4050 with and without Unity → choose defaults |
| Validation of outputs | Repeatable runs. |
| Errors | Timeout or server error: one retry, then templates everywhere; logged with prompt version and model digest. |
| Hallucinations | Output must match a JSON schema whose enums are approved ids; the grounding validator rejects invented drugs, values, diagnoses, events and hidden facts. |
| Inconsistent results | Output is cross-checked against the structured case or facts it was given; any mismatch rejects it. |
| Model unavailable | Feature switch reports off; templates everywhere. The session never waits on the model. |
| Invalid input | Inputs are schema-validated before the model is called; invalid input is a 4xx with field errors. |
| Tests | benchmark protocol |
| Metrics | tok/s; VRAM; schema validity |
| Baseline comparison | — |
| Acceptance | Report with a default per task and per machine. |
| GTX 1660 SUPER (desktop) | Desktop GTX 1660 SUPER (Turing, 6 GB, no tensor cores): Qwen3-4B Q4 (about 2.5 GB weights) plus a 4k-token KV cache is expected to fit with room for ASR; Qwen3-8B Q4 (about 5.2 GB) leaves almost no room for context and is expected to need partial CPU offload (slow). Throughput to be measured. |
| RTX 4050 Laptop | Laptop RTX 4050 (Ada, 6 GB, tensor cores, power-limited): faster per token than the desktop for the same model, but if Unity VR renders on this GPU the model must share VRAM with the scene; budget about 2 GB for a model while Unity runs, or run the model on the desktop. |
| Memory | 16 GB system RAM on the desktop limits CPU offload to small models; laptop RAM to be recorded in the benchmark. |
| Latency | Interactive replies: p95 under 3 s; generation stages: under 25 s or served from the pre-generated pool; offline jobs: no limit. |
| Deployment | Recommended split (to confirm by p1-ai-infrastructure-s02): inference service on the desktop GPU, Unity on the laptop GPU, over the local network. Single-machine mode: Qwen3-1.7B or CPU inference plus the pool. Remote inference only for offline jobs, never with real personal data. |
| Tasks | p1-ai-infrastructure-s01; p1-ai-infrastructure-s02; p1-ai-language-s02 |
