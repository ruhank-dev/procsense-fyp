## 1. Intended user experience

After the session the trainee reads a short, encouraging, specific debrief in plain language, with every point linked to the moment it happened; the template version is always available.

## 2. What exists and what is missing

- DebriefFacts
- template debrief
- grounding validator with debrief mutation checks

**Missing:**

- served model
- rewrite prompt
- 50-session mutation run

**Deterministic foundation:** DebriefFacts are the only facts.
