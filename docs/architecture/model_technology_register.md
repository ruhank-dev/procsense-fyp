# Model and technology decision register

_Generated by `tools/plans/pipeline_docs.py` from `procsense_full_pipeline.json` — do not edit by hand._

LLM-first, model-aware: for each responsibility a served LLM or a pretrained model was considered first; a simpler deterministic, statistical or retrieval method is chosen only where the row says why. Nothing here is trained except the P2 classifier (E60), which ships only if it beats the P1 LLM classifier. Fine-tuning an LLM (E65) and image-generating models (E64) are not used at runtime; both are kept as staged offline research tracks (PH-24) with their history, not rejected.

Hardware: a desktop GTX 1660 SUPER (6 GB) and a laptop RTX 4050 (6 GB), both benchmarked in `p1-ai-infrastructure-s02`; Ollama is not installed yet (checked 12 October 2026) and installing it is roadmap task `p1-ai-infrastructure-s01`.

## Hardware assessment (both GPUs)

- **Desktop:** GTX 1660 SUPER 6 GB (Turing, no tensor cores), 16 GB RAM, Ryzen 5 2600 6 cores / 12 threads, Windows 11 (measured 12 Oct 2026)
- **Laptop:** RTX 4050 Laptop 6 GB (Ada); RAM, CPU and power limit to be recorded in p1-ai-infrastructure-s02
- **Rule:** Hardware is not a reason to drop a feature: each capability has a staged deployment (quantised, smaller, CPU, async, precomputed, split service, remote offline) chosen by the benchmark.

| Profile | GTX 1660 SUPER (desktop) | RTX 4050 Laptop | Memory | Latency | Deployment |
|---|---|---|---|---|---|
| llm | Desktop GTX 1660 SUPER (Turing, 6 GB, no tensor cores): Qwen3-4B Q4 (about 2.5 GB weights) plus a 4k-token KV cache is expected to fit with room for ASR; Qwen3-8B Q4 (about 5.2 GB) leaves almost no room for context and is expected to need partial CPU offload (slow). Throughput to be measured. | Laptop RTX 4050 (Ada, 6 GB, tensor cores, power-limited): faster per token than the desktop for the same model, but if Unity VR renders on this GPU the model must share VRAM with the scene; budget about 2 GB for a model while Unity runs, or run the model on the desktop. | 16 GB system RAM on the desktop limits CPU offload to small models; laptop RAM to be recorded in the benchmark. | Interactive replies: p95 under 3 s; generation stages: under 25 s or served from the pre-generated pool; offline jobs: no limit. | Recommended split (to confirm by p1-ai-infrastructure-s02): inference service on the desktop GPU, Unity on the laptop GPU, over the local network.
