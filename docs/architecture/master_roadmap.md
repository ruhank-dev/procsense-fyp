# ProcSense master roadmap (AI features and live generation)

_Generated by `tools/plans/pipeline_docs.py` from `procsense_full_pipeline.json` — do not edit by hand._

Dependency-ordered phases. Existing plan step ids are kept (the composer lineage `p1-scenario-composer-difficulty` s01 to s05 is unchanged); new work has new step files in `p1-dataset-analysis`, `p1-live-scenario-generation`, `p2-ai-learning-analytics` and `p2-ai-advanced-simulation`. Milestone numbers are ids, not order.

Specified on 12 October 2026; the state of each feature is in [feature_implementation_matrix.md](feature_implementation_matrix.md).

## Critical path

PH-01 → PH-02 → PH-03 → PH-05 → PH-09 → PH-10 → PH-11 → PH-12

The first fresh scenario needs no language model: dataset profiles, packs, blocks, solver, numeric and media generation, validation and packaging. The LLM, voice and classifier phases run in parallel and plug in when their blockers clear; the AI composer, the knowledge base and personalisation (PH-20 to PH-23) make that fresh case AI-composed and personalised.

**AI critical path** (the explicitly AI-composed, personalised scenario): PH-20 → PH-07 → PH-22 → PH-08 → PH-23.
