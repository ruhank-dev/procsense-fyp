## Design note for the ECG generator (p1-live-scenario-generation-s06)

Rhythms with real recordings (normal, tachycardia, atrial fibrillation, bradycardia, heart block, SVT, inferior MI) are chosen from PTB-XL by label and rate and shown through the approved picture library. A rate or noise outside what the table shows for the class is not generated. Hyperkalaemia and hypokalaemia have no PTB-XL label: the generator uses the parametric pattern only after the cardiology reference for the parameters is read (OQ-05); NeuroKit2 `ecg_simulate` can match a class's rate and noise but does not model electrolyte changes, so it is not enough for those two.
