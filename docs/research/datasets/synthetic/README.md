# Synthetic datasets

Every synthetic dataset in the repository has a card (schema `tools/synth/card_schema.json`). Generated by `tools/synth/publish.py`; do not edit.

| Id | Dataset | Purpose | Generator | Use |
|---|---|---|---|---|
| SD-001 | Seeded text inconsistencies | Cases in which one line of the patient's own text was changed to contradict the structured case, to measure the recall of the text consistency critic against the rule-based checks. | `tools/generation/inconsistency_set.py` | dev only |
| SD-002 | Golden runs of generated cases | Six generated practice cases, each with the correct-path script of the case it keeps the story of and the engine's expected hashes, so the engine plays generated content identically on every platform. | `tools/golden/generated.py` | dev only |
| SD-003 | Shared difficulty histories | Thirteen session histories with the ratings the engine and the Python mirror must both compute, so the two implementations cannot drift apart. | `server/generation/make_vectors.py` | dev only |
| SD-004 | Simulated learners (personalisation experiment) | Learners with a hidden mastery per behaviour who play sessions, to test the learner model and to compare targeting policies against the truth. | `server/personalisation/simulate.py` | dev only |
| SD-005 | Gold scenarios and retrieval queries | The authored cases summarised as reference scenarios, and problem-label queries with the cases that hold them, to test generated scenarios and the retrieval index. | `tools/generation/build_packs.py` | dev only |
| SD-006 | Communication act utterances (classifier set) | Labelled sentences of a trainee's speech, one communication act each, in frozen train, dev and test splits split by speaker, to calibrate and test the communication act classifier. | `tools/synth/gen_utterances.py` | dev only |
| SD-007 | Communication act sentences in eight simulated writing styles (model-written, model-labelled, NOT independent) | To check whether a communication act classifier trained on some writing styles holds up on styles it has not seen: train, dev and test splits whose author profiles never overlap, with negation, self-correction, incomplete speech, deliberate ambiguity, NONE cases and real speech-recogniser copies. | `tools/bench/synthetic.py` | dev only |
