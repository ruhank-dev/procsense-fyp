# Synthetic datasets

Every synthetic dataset in the repository has a card (schema `tools/synth/card_schema.json`). Generated by `tools/synth/publish.py`; do not edit.

| Id | Dataset | Purpose | Generator | Use |
|---|---|---|---|---|
| SD-001 | Seeded text inconsistencies | Cases in which one line of the patient's own text was changed to contradict the structured case, to measure the recall of the text consistency critic against the rule-based checks. | `tools/generation/inconsistency_set.py` | dev only |
| SD-002 | Golden runs of generated cases | Fourteen generated practice cases (8 S1, 6 S2), each with the correct-path script of the case it keeps the story of and the engine's expected hashes, so the engine plays generated content identically on every platform. | `tools/golden/generated.py` | dev only |
| SD-003 | Shared difficulty histories | Thirteen session histories with the ratings the engine and the Python mirror must both compute, so the two implementations cannot drift apart. | `server/generation/make_vectors.py` | dev only |
| SD-004 | Simulated learners (personalisation experiment) | Learners with a hidden mastery per behaviour who play sessions, to test the learner model and to compare targeting policies against the truth. | `server/personalisation/simulate.py` | dev only |
| SD-005 | Gold scenarios and retrieval queries | The authored cases summarised as reference scenarios, and problem-label queries with the cases that hold them, to test generated scenarios and the retrieval index. | `tools/generation/build_packs.py` | dev only |
| SD-006 | Communication act utterances (classifier set) | Labelled sentences of a trainee's speech, one communication act each, in frozen train, dev and test splits split by speaker, to calibrate and test the communication act classifier. | `tools/synth/gen_utterances.py` | dev only |
| SD-007 | Communication act sentences in eight simulated writing styles (model-written, model-labelled, NOT independent) | To check whether a communication act classifier trained on some writing styles holds up on styles it has not seen: train, dev and test splits whose author profiles never overlap, with negation, self-correction, incomplete speech, deliberate ambiguity, NONE cases and real speech-recogniser copies. | `tools/bench/synthetic.py` | dev only |
| SD-008 | Communication act sentences, version 2, in twelve simulated writing styles (model-written, AI-judged, NOT independent) | To go on evaluating the communication act classifier while no human authors or labellers can be arranged: a larger and more varied set (train, dev and test sharing no author profile and no scenario group) with negation, self-correction, incomplete speech, ambiguity and recogniser-style noise, labelled by two AI judge configurations, so that three classifiers can be compared and the guards against crediting critical speech measured. It is not validation and says nothing about real trainee speech. | `tools/bench/synthetic2.py` | dev only |
| SD-009 | Communication act sentences, version 3, a fresh hold-out (model-written, AI-judged, NOT independent) | To measure the changes made to the classifier after the version 2 test split had been scored once (a retrained head, a critical-mass cap, a longer cue list) on sentences nobody has tuned against: 300 new sentences from three new author profiles in two new scenario groups. | `tools/bench/synthetic3.py` | dev only |
| SD-010 | Held-out text inconsistencies for the critic, worded differently from the first set | To measure the model critic fairly after deterministic rules saturated the first seeded set (SD-001): 134 contradictions of 7 kinds worded without the lexicon's words, written after the rules and frozen before any critic run. | `tools/generation/inconsistency_set_v2.py` | dev only |
| SD-011 | Evasive sentences that touch critical content (a tuning set and three hold-outs) | To count how often the speech classifier would credit a sentence about an allergy, an identity check, consent, the fasting state, a worsening sign or a structured handover under an ordinary act when the words avoid the obvious cues, and to measure the guards against it. | `tools/bench/adversarial_critical.py` | dev only |
| SD-012 | Seeded stress lines for the patient dialogue (normal, abnormal, ambiguous, contradictory, adversarial) | To test, repeatably and offline, that the patient dialogue never leaks a withheld fact, never talks about its instructions or being a program, never gives a dose or clinical advice and stays short, when it is asked plain, noisy, vague, contradictory and manipulative questions. | `tools/ai/dialogue_stress.py` | dev only |
| SD-013 | Seeded requests to the live scenario generator (normal, boundary, ambiguous, contradictory, adversarial) | To show, repeatably and offline, that the generation entry (request contract and pipeline) refuses what it should refuse with a reason, and for everything it accepts ends in a sealed, gate-passing, reproducible package or the documented fallback, whatever the request looks like. | `tools/generation/request_fuzz.py` | dev only |
