# Zero-shot NLI (facebook/bart-large-mnli, no fine-tuning) against the current classifier

_Generated by `tools/bench/nli_report.py` from `reports/ai/nli-zero-shot.json`; do not edit by hand. SYNTHETIC: `tests/action_bench_v1`, labels by construction (no model labelled a row), one author family. There is NO independent human-labelled evaluation in the repository (EX-01, EX-18), so nothing here shows how either system behaves on real speech. The experiment changed nothing in the application: no classifier, scoring, Unity or feature-flag file._

## Fixed before any split was scored

* Model `facebook/bart-large-mnli`, revision `d7645e127eaf1aefc7862fd59a17a5aa8558b8ce`, float32 on cuda (torch 2.6.0+cu124, transformers 4.46.3); isolated environment `artifacts/nli-env`, weights in `artifacts/hf-cache` (both git-ignored).
* Premise = the sentence alone (the production classifier also receives only the sentence). Hypothesis = "The speaker {the label's own definition}." for each of the 20 labels, all scored, no shortlist. NONE's definition says "the acts above" and has no meaning as a hypothesis, so it is worded from its own parenthesis (the only changed hypothesis).
* Mode: single label (the rubric says one label per sentence, first rule that fits; the current classifier is an argmax): softmax over the entailment logits of the 20 hypotheses. Raw contradiction/neutral/entailment logits are kept in the artifacts. The scores rank labels; they are not calibrated probabilities.
* Abstention is separate from NONE. Its threshold (top score >= 0.53) is the smallest on a 0.01 grid at which the answered dev rows reach 0.80 accuracy. Credit thresholds per label come from the repository's `classify.calibrate` (credited precision 0.8) on dev. Both were fitted on dev only and applied unchanged to test and test2; a label with no usable threshold is never credited.

## Limitations

* Synthetic constructed sentences from one author family, 188 core rows per split; labels by construction; a derived NONE label for the non-performed rows. No independent human-labelled set exists, so neither system is validated on real speech.
* One hypothesis wording (the ontology's own definitions) plus one dev-only alternative. Better-written per-label hypotheses might help; that is a different experiment.
* No dialogue context (none exists where the classifier runs). Latency is measured on one desktop; fp16 is slow on this Turing card and a newer GPU would differ.
* Dev, test and test2 were each scored once with the frozen setup; the dev results fix tau and the thresholds, so dev numbers are not held-out.

## Recommendation

BART-large-MNLI zero-shot is not better than the current baseline. Forced-choice accuracy is 0.261 against 0.803 on test and 0.394 against 0.872 on test2; it never names NONE, and its scores hardly separate right from wrong (abstention leaves almost nothing answered correctly). Through the unchanged gate it credits 13/140 legitimate sentences on test against 66/140, and only the production guards stop its false credits. It needs about 206.7 ms and 1869 MB of video memory a sentence against 14.5 ms. The evidence does not justify further testing of this exact option. Unresolved: whether an NLI model with searched hypotheses or a few labelled examples would do better, and anything about real trainee speech (needs the independent set of EX-01/EX-18). Speech-based scoring stays OFF.
