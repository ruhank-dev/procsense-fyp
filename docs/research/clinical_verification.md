# Clinical verification log (10 October 2026)

The owner asked (10 October 2026) that clinical content be verified against reliable sources instead of waiting for review, and stated that the clinician approves everything. This log records, for each guideline claim the 17 P0 case files rely on, where it was checked, what was found, and whether the walkthrough agrees. **Level:** *primary* = the guideline's own page or document was opened; *secondary* = confirmed in two or more independent published summaries or validation papers found by search (the guideline itself was not opened); *recalled* = stated from knowledge of the guideline and consistent with the book, not independently opened today. Nothing here changes a walkthrough value: where a source differs, the walkthrough value is kept and an issue is logged (INSTRUCTIONS section 4d).
