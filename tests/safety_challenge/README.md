# tests/safety_challenge

Unsafe, non-assertive, ambiguous and out-of-context trainee speech, generated by `tools/bench/metamorph.py` from `tools/bench/safety_seeds.py` (p1-ai-language-s16, ADR-0023). **Synthetic, builder-written, labels by construction and PROVISIONAL; no person has reviewed any row. Not independent validation.**

| file | what it is |
|---|---|
| `dev.jsonl`, `challenge.jsonl`, `final.jsonl` | the rows (id, text, act, seed family, seed text, template, category, expected outcome, condition, session group and position, critical flag, provenance, review status). `dev` was used to change the implementation; `challenge` was looked at once, then used for development; `final` was scored once per configuration and never used for a change. The expected labels are in these files: reviewers must not see them. |
| `manifest.json` | counts per split and category, review status, leakage report (no seed family or template crosses a split), near-duplicates dropped, sha256 of each split. `tools/bench/metamorph.py --check` compares them with the generator. |
| `taxonomy.json` | the categories, their expected decision, safeguards, residual risks and tests |
| `review_sheet.csv` | the blind sheet for human reviewers (no expected label, no system output): `tools/bench/safety_review_sheet.py` |
| `regression_cases.json` | the must-not-credit sentences the unchanged `4a2ed00` implementation credited (development and challenge), kept as permanent regression cases: `tools/bench/safety_regression.py` |

Do not edit a `.jsonl` by hand and do not change the generator to fit a reviewer's label: a relabelling is a separate override file that names the reviewers (docs/testing/safety_challenge_review.md). The final split is scored once per configuration by `tools/bench/safety_eval.py --split final --final`.
